# @gotyoudesigns 成效規則

資料來源：Threads 成效中心（shu_threads studio）「內容成功模式」「最佳發文時間」「最佳貼文」三個頁面，2026-09-15 讀取，樣本為近一年約 131 篇。
「倍數」＝該類貼文平均互動 ÷ 整體平均互動（整體平均約 3.3）。

這些是**這個帳號自己**的數據，不是社群通則，數字會隨新貼文變動。成效中心開著時（本機 http://localhost:3700，頁面 `#/patterns`、`#/times`、`#/best`），先重看一次再引用。

## 形式

| 因素 | 倍數 | 寫作時怎麼做 |
|---|---|---|
| 單張圖片 | 3.64×（6 篇） | 每篇配一張圖卡。樣本小，但訊號很強 |
| 純文字 | 0.91× | |
| 輪播 | **0.05×**（6 篇全墊底） | 不做輪播，也不要把 IG 輪播圖卡直接搬過來 |

## 文字

| 因素 | 倍數 | 寫作時怎麼做 |
|---|---|---|
| 200 字以上 | 1.29× | 正文寫 220–380 字 |
| 80–200 字 | 0.75× | |
| 80 字以內 | 0.62× | 不寫短文 |
| 內文有問句 | 1.37× | 最後一句是具體的問句 |
| 問句當開頭 | **0.65×** | 第一句不要是問句 |
| 反轉／提醒開頭 | 1.23× | 最推薦的開頭 |
| 短句破題 | 0.99× | 可以用 |
| 陳述開頭 | 0.97× | 可以用 |
| 有條列 | 1.20× | 適度使用 |
| 有 emoji | 1.17× | 只用 1️⃣ 這類編號與 ❌ ✅ 對照符號 |
| 有主題標籤 | 1.14× | 結尾放主題標籤 |
| 正文含連結 | **0.63×**（不含連結 1.09×） | 連結放第一則留言 |

## 高成效貼文常出現的詞

wordpress、seo、安全、衝突、主機、完整、系統、長期、rank math、名單
