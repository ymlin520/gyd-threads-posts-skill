# posts.js 格式與圖卡規格

## 檔案格式

```js
module.exports = [
{
  slug: 'uptime-monitor',          // 小寫英數與連字號，用在圖檔名
  title: '停機監控',                // 資料夾名稱，8 字內，不可含 \ / : * ? " < > |
  category: '維護',                 // 類別，用來檢查相鄰兩篇是否同類
  structure: '算帳',                // 故事／迷思對照／自我檢查／算帳／立場／經典條列
  angle: '設免費 uptime 監控，避免週末停機 61 小時才發現',  // 核心建議一句話，下一批比對重複用

  meta: '網站監控',                 // 圖卡右上角小字
  eyebrow: '週五晚上掛掉，週一才發現', // 標題上方的橘色小字
  h1: '網站掛了<br>是<em>客戶告訴你的</em>',  // 兩行，用 <br> 分行；<em> 內的字變橘色
  type: 'stat',                     // dot／num／numsub／vs／stat
  stat: { big: '61 小時', cap: '週五 20:00 掛掉 → 週一 09:00 才發現' },  // 只有 stat 版型需要
  items: ['廣告照扣錢，點進來全是錯誤頁', '想詢問的人轉頭找別家', '免費監控，十分鐘設好'],
  punch: '出事不可怕，晚發現才可怕。',   // 深色結語框
  tagline: 'UptimeRobot ／ Better Stack', // 右下角小字

  firstComment: 'https://hostswp.com/...', // 選填：要放在第一則留言的連結或補充
  text: `網站掛掉這件事，很多老闆是客戶打電話來才知道的。
...
#網站維護 #網站監控`,
},
];
```

## 五種圖卡版型

| type | items 格式 | 項數 | 適合的結構 |
|---|---|---|---|
| `dot` | `'文字'` | 3–4 | 經典條列、立場 |
| `num` | `'文字'` | 3–5 | 自我檢查、故事 |
| `numsub` | `['標題', '說明']` | 3 | 經典條列、故事 |
| `vs` | `['誤會', '事實']`（不要加 ❌ ✅，版型自己會畫圖示） | 3 | 迷思對照、立場 |
| `stat` | `'文字'`，另外要填 `stat.big` 與 `stat.cap` | 2–3 | 算帳 |

圖卡只放骨架：標題、3 到 5 個重點、一句結語。細節留在正文，讀者才有理由去讀文字、留言。

## 長度上限

中文字算 1 個寬度，英數字與半形符號約算 0.55。

| 欄位 | 上限 | 備註 |
|---|---|---|
| meta | 14 | |
| eyebrow | 20 | |
| h1 每一行 | 11 | 最多兩行；英文字（例如 WordPress）和中文之間留一個半形空格，標題字體下黏在一起會很擠 |
| dot／num 項目 | 18 | |
| numsub 標題／說明 | 15／23 | |
| vs ❌ 句／✅ 句 | 17／19 | |
| stat.big | 6.5 | 例如「61 小時」「24 / 7」 |
| stat.cap | 23 | |
| punch | 21 | |
| tagline | 20 | 過長會撞到左下角的 hostswp.com |

`build.js` 會先依上表提出警告，渲染後再實際量測換行與間距。兩者結果不一致時，以實際量測為準。

## 固定的品牌元素（寫在 build.js 裡，每批都不要改）

- 尺寸 1080×1350（4:5）
- 米白底 #F7F5F1、主色橘 #F58220、深色 #171717、分隔線 #D8D3CC
- 標題用 Noto Serif TC Black，內文用 Noto Sans TC
- 左上角是 GOT YOU DESIGN 織紋標記，左下角是 hostswp.com
- 白色內容卡搭配左側橘色側條，底部是深色結語框
